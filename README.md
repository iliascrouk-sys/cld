# Webs de clientes

Un directorio por cliente. Cada uno es un sitio estático independiente —HTML,
CSS y JavaScript planos, sin build ni dependencias— que se abre haciendo doble
clic en su `index.html` y se publica subiendo la carpeta a cualquier hosting
estático.

| Carpeta | Cliente | Estado |
|---|---|---|
| [`la-cava-gastrobar/`](la-cava-gastrobar/) | La Cava Gastrobar · Cuenca | Con fotos y carta reales. Falta confirmar horario y completar la carta. |
| [`hostal-de-cuenca/`](hostal-de-cuenca/) | Hostal de Cuenca | Estructura y diseño listos. Faltan teléfono, dirección, precios y fotos. |

Cada carpeta tiene su propio `README.md` con lo que queda pendiente y cómo
tocar el contenido.
